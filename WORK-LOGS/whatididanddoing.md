- built the sim backend (08.09.2026): numpy grid world in simulation/grid_env.py (trash spawning, sensor radius queries, wall bounds, collection), gemini-powered brain in core/llm_brain.py (json parsing + greedy fallback for every failure path, runs offline with no key), 3-rover asyncio swarm in core/swarm_async.py. tests/test_sim.py runs the whole swarm against a fake api client, no network needed, all checks green. next: prompt tuning (model hugs walls), benchmarking llm vs greedy, rover-rover trash claiming. hardware after the sim earns it.
- NEURO-SYMBOLIC REWORK (08.09.2026, later same day): moved to a hybrid brain. gemini is now strictly the task allocator (one async json call, assigns 1 trash per rover, greedy fallback if throttled/garbage) and a-star with manhattan heuristic does all the actual driving step-by-step in simulation/grid_env.py. the old "ask the llm for one move per tick" design burned tokens on steering and the model hugged walls anyway. full board now cleans in ~70 ticks. also shipped the visual layer: simulation/visualizer.py (pygame, dark retro-hacker look, trails, target lines, scanlines) and generate_gif.py which records 100 headless frames into assets/demo.gif, committed so github shows the sim running at the top of the readme. 46 checks green in tests/test_sim.py including a-star-vs-bfs optimality on 30 random cases.
- MODEL BUMP (08.09.2026): allocator moved to gemini-3.8-flash (GA as of sep 2). set thinking_level to low for the allocation calls since a 40-tile assignment prompt doesnt need deep reasoning tokens, and 3.8-flash rejects the old sampling params anyway (we never used them). confirmed the model id + thinking_level support straight from google's docs before touching the code.
